# Сайт «Мама сделала»

Статический сайт: `index.html`, `css/`, `js/`, `img/`. Никакой сборки не нужно.

## Как работаем
1. Правим файлы на компьютере и проверяем локально: в папке `site` запускаем `python -m http.server 4580` и открываем http://localhost:4580.
2. Коммитим и пушим в GitHub.
3. Хостинг забирает изменения из GitHub (папка для публикации: `site`).

## Как поменять цены
Все цены и названия лежат в одном файле: `js/prices.js`. Меняйте число после `price:` и сохраняйте файл.
Чтобы добавить фото к набору, положите файл в `img/` и впишите путь в `photo: "img/имя.webp"`.

**После любых правок CSS или JS** увеличьте номер версии в `index.html` (`?v=4` → `?v=5` у `style.css`, `prices.js`, `main.js`), иначе браузеры посетителей могут показать старые цены из кэша.
